# sitescope 1.4.1

## Features

None.

## Bug fixes

- `unlock`, `lock`, `status` and the `vault` commands no longer fall back to
  built-in paths when they find no hub config. They used to act on
  `/run/sitescope/control.sock` or `/var/lib/sitescope/vault.age`, which on
  a hub with other paths meant prompting for a vault it doesn't use.

## Breaking changes

- Without `-config`, `$SITESCOPE_CONFIG` or `/etc/sitescope/config.json`,
  those commands now exit with an error naming the three. An explicit
  `-socket` or `-vault` still needs no config. The NixOS module always
  writes `/etc/sitescope/config.json`, so its hosts see no change.
