# sitescope 1.2.0

## Features

- `unlock`, `lock`, `status` and `vault …` take the control socket and vault paths
  from the hub's config (`hub.controlSocket`, `hub.vault`), found through `-config`,
  `$SITESCOPE_CONFIG` or `/etc/sitescope/config.json`. A hub outside the NixOS
  module no longer needs `-socket` and `-vault` on every command.

## Bug fixes

- None.

## Breaking changes

- None. With the module's config the paths are the same as before; `-socket`
  and `-vault` still override.
